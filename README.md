# AI Industry Stack

An interactive map of the AI industry: 11 layers, from physical infrastructure (L0) up to applications (L10), with the buckets inside each layer and the companies that sit in them.

**[Open the site →](https://fanatic-af.github.io/ai-industry-stack/)**

## How to use it

- **Pick a layer** on the home page to see its buckets and companies. Click a bucket title to zoom in.
- **Click a company** to open its LinkedIn page (in the LinkedIn app on phones, when installed).
- **Applications (L10)** has an industry filter, plus the order used to place a product when it could fit more than one bucket.
- **Search** with `/` or `Ctrl+K` / `⌘K` to jump to any company or bucket.
- **Rules** explains how companies are placed in a layer.
- **Extra examples** (✦) shows or hides companies added beyond the original taxonomy.
- **Keyboard:** `←` / `→` move between layers and `Esc` goes back up.

## Suggest an addition

Know a company that belongs on the map, or a bucket or layer that is missing? Press **＋ Suggest** on the site. It opens a pre-filled GitHub issue (you need a free GitHub account). Approved suggestions appear on the map marked with ● and your name, if you gave one.

You can also [open a suggestion directly](https://github.com/fanatic-af/ai-industry-stack/issues/new/choose).

## Built with

Plain HTML, CSS and JavaScript, with no build step. The taxonomy lives in `data.js`, and the site is hosted on GitHub Pages.
